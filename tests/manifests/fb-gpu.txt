# finite-difference checks in fb.txt. Tolerances were set FROM the measured
# parity (measure 7.1e-08, ortho 2.1e-07, actor 8.5e-08 on Apple), not
# defensively — see docs/BFM_ZERO_SHOT_RL.md §13 M2.

# ⚠ A GPU-vs-CPU band written on Metal is a TF32 trap on CUDA: compare weights
# bit-for-bit first if a 5090 run lands outside it.

tests/deep_agents/test_fb_cpr_gpu_parity.mojo

tests/deep_agents/test_fb_cpr_online_smoke.mojo

# The captured train step allocates nothing per call — any per-call alloc is a
