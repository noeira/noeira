# nn/distributed simulator manifest — `pixi run -e apple test-nn-distributed`
# (or -e nvidia).
#
# Every gate here runs all N ranks on ONE device (ProcessGroup.shared), so a
# Mac or a single GPU is enough; the multi-GPU form of each test is a build
# with `-D DDP_DEVICES` on a 2-GPU box. Each test compares a distributed run
# against plain DDP or a plain training loop, bit for bit where the arithmetic
# allows. Without an accelerator every entry prints a skip and passes.
