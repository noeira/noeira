# ACT / nn GPU manifest — `pixi run -e nvidia test-act-gpu` (or -e apple).
#
# GPU paths are gated against the CPU paths, which carry the comparison against
# the reference. Setup is one 16 KB untar for the first entry, and the LAST
# entry additionally needs a converted store (`$ACT_STORE`, or the newest one
# in the cache) because it compares a device-resident sampler against the host
# one — there is nothing to compare without data:
#
#   mkdir -p /tmp/act_ref && tar xzf tests/fixtures/act_ref_xattn.tgz -C /tmp/act_ref
#
# No torch, no dataset, no `act-ref` environment. The other three are fully
# self-contained.
#
# ⚠ These run under `mojo run` (JIT), which never invokes ld. Building them with
# `mojo build` on APPLE needs `-Xlinker -ld_classic` — the expanded graph types
# mangle past that linker's symbol-length limit. Not an issue on CUDA.

# The attention leaf: forward, backward, masked and unmasked. Reads the fixture.
tests/nn/test_cross_attention_gpu.mojo
# BatchNorm2D's backward in BOTH modes. The eval arm is the one that was
# silently returning zero for gamma/beta on GPU.
tests/nn/test_batch_norm_2d_eval_backward_gpu.mojo
# The real ResNet18 backbone: forward, grad_input, conv grads, BN affine grads.
tests/nn/test_resnet18_gpu.mojo
# The whole ACT model: forward, one Adam step, BN state, and predict().
# Uses a two-conv stub backbone so it compiles in reasonable time; the real
# backbone is covered by the entry above.
tests/deep_agents/act/test_act_gpu_vs_cpu.mojo
# FrozenBatchNorm2d semantics (CPU + GPU legs), vs torchvision's own class.
# Needs `--only frozen_bn` from the reference dump. Not wired into ACT yet —
# `set_attr["frozen"]` is what a backbone would be built with.
tests/nn/test_batch_norm_2d_frozen_gpu.mojo
# The device sampler: same rows in, same tensors out as the host path. Needs a
# store; skip it (or set ACT_STORE) if you have not converted one.
tests/deep_agents/act/test_act_dataset_gpu.mojo
# Image augmentation (DR plan Phase 1): off == the original gather bit-exact,
# the augmented kernel == the host twin to one byte, validation never
# augmented. Needs a store, like the entry above.
tests/deep_agents/act/test_act_augment_gpu.mojo
# Device-resident logging: the window `train_metrics`/`val_metrics` drain must
# equal what `_read_terms`/`read_clip_norm` download off the same forward.
# Self-contained (stub backbone, synthetic batch) — no store, no fixture.
tests/deep_agents/act/test_act_device_metrics.mojo

# GradPenalty device path against the host path (same net, same input).
tests/nn/test_grad_penalty_gpu.mojo
