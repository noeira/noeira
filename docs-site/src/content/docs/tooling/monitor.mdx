A robot-learning project rarely lives on one machine. Training happens on a
GPU box, recording on the computer beside the robot, deployment on the robot's
own board. noeira cloud is where those machines meet: a hosted dashboard and
storage that every noeira program can report to.

## What it is for

- **Runs, live.** Every scalar a training driver logs — returns, losses,
  success rates, validation curves — streamed as it happens, with the run's
  configuration beside it, and runs compared side by side.
- **Policies.** Which checkpoint fills which role in a project, and why it was
  promoted.
- **Datasets and artifacts.** Recordings and checkpoints pushed from one
  machine and pulled onto another, so a project follows its data.

## Without it

Nothing changes. Every run writes its directory, checkpoints and metrics on
the machine that ran it, and the loggers stay silent when no server is
configured. `CsvLogger` records the same metrics to a file, and
`CompositeLogger` writes to both. See [logging](/tooling/logging/) and
[projects and runs](/concepts/projects/).
